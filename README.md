# ☕ Java — Aprendizado

Repositório com os meus estudos práticos de Java, organizados por tópico conforme avanço no aprendizado.

## 📁 Estrutura

| Pasta | Conteúdo |
|---|---|
| [`01-introducao/`](./01-introducao/) | Entrada de dados com `Scanner`, operadores lógicos e relacionais |
| [`02-estruturas-de-controle/`](./02-estruturas-de-controle/) | `for`, `if/else` — tabuada, cálculo de IMC, pares e ímpares |
| [`03-exercicios/`](./03-exercicios/) | Exercícios práticos: idade, área de figuras, diferença entre valores |
| [`04-orientacao-a-objetos/`](./04-orientacao-a-objetos/) | Classes, encapsulamento, construtores, getters — sistema de conta bancária |
| [`05-maven/`](./05-maven/) | Introdução ao Maven: estrutura de projeto e `pom.xml` |

## 🛠️ Tecnologias

- **Java 21**
- **Maven**
- **IntelliJ IDEA**

## ▶️ Como executar

Cada arquivo é independente e pode ser compilado diretamente pelo terminal:

```bash
# Compilar
javac NomeDaClasse.java

# Executar
java NomeDaClasse
```

> Para o projeto Maven (`05-maven/`), use `mvn compile` e `mvn exec:java`.
